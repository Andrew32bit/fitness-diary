# Дневник питания, веса и тренировок

Личное офлайн-приложение: еда и КБЖУ, вес, тренировки из Apple Health, статистика.
Данные хранятся только на устройстве в IndexedDB и никуда не отправляются.
В этом репозитории лежит исключительно код — никаких персональных данных.

## Разработка

    npm install
    ./node_modules/.bin/vite
    npm test

## Как попадают данные

- История тренировок: Здоровье → «Экспортировать все данные о здоровье» →
  `node scripts/parse-export.mjs export.xml -o workouts.json` → импорт файла в приложении.
- Новые тренировки: HealthFit складывает TCX в iCloud Drive после каждой тренировки → импорт файла.
- Еда и вес: ввод в приложении или вставка JSON из буфера.

## Бэкап

Настройки → «Экспорт всех данных». iOS удаляет данные приложений, которыми не пользуются
семь дней, поэтому выгрузка раз в неделю обязательна. Приложение напоминает само.
